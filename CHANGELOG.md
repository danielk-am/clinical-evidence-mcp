# Changelog

## 0.1.0, 2026-08-01

- Added stateless Streamable HTTP MCP transport with bearer authentication.
- Added token creation, listing, revocation, and email-account binding.
- Added PubMed, Europe PMC, ClinicalTrials.gov, and openFDA tools.
- Added patient-identifier checks, per-account rate limiting, source metadata, and safety notes.
- Added an optional account-gated contract for private syndicated evidence sources.
